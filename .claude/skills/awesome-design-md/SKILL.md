# Awesome DESIGN.md

Each folder in `design-md/<brand>/` holds a `DESIGN.md` (tokens, type, layout, components, motion, voice) and a `README.md`. Source: VoltAgent/awesome-design-md (MIT).

How to use:
1. List brands with `ls .claude/skills/awesome-design-md/design-md`.
2. Read only the 1–3 files relevant to the question. They are long, so search them (`grep -n "## " design-md/<brand>/DESIGN.md`) and read the sections you need.
3. Use them as **references, not templates**. This project has its own identity (docs/DESIGN.md: Furtil black + yellow #FFCC00, Mercosul plate as signature). Borrow principles such as spacing rhythm, card treatment and motion timing. Never copy another brand's palette, logo or copy.
